# coverage-matrix — probe-v0.8

케이스 × R(그 케이스 자신의 요구사항 커버리지 표, R1~R10)을 그대로 전사한다.
R 번호는 위치적(positional)이다 — 케이스마다 다른 시나리오의 요구사항이므로
"s1의 R3"과 "s2의 R3"은 다른 요구를 가리킨다(교차 대조는 하지 않는다,
그 역할은 metrics-comparison.md의 METRICS 행 대조가 맡는다). 셀 단어는 각
케이스 `FINDINGS.md`의 요구사항 커버리지 표에서 **판정 열의 선두 단어만**
verbatim 전사했다(부연 설명은 friction-matrix.md와 FINDINGS.md 원문에 있다).
누락된 R은 "미측정"으로 쓴다 — 다섯 케이스 전부 R1~R10을 채웠으므로 해당 없음.
